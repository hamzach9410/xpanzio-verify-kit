# Xpanzio Verify Kit (`@xpanzio/verify-kit`)

Client-side verification utility for authenticating digital credentials and training certificates issued by **[Xpanzio Technologies](https://xpanzio.com)**.

Live Verification Portal: **[https://xpanzio.com/verify](https://xpanzio.com/verify)**

---

## Features

- Instant SHA-256 / Ed25519 digital signature validation
- QR code payload parsing
- Offline verification support for zero-trust environments
